# Bookworm - Bookstore Management (Frontend)

Open `index.html` in any browser. No install or server needed.

## Login
- admin@bookworm.com / admin123
- reader@bookworm.com / read123

## Structure
- index.html - page markup (login + app shell)
- css/style.css - styles (light/dark theme, reader, responsive)
- js/app.js - books data, chapter generator (8-10 chapters x 120 words per book), views, full-screen reader

## Features
Home (categories, trending, popular), book page with chapters, full-screen reader,
Library (add/remove books), Community, AI Integration (keyword recommender), Settings, Help, search + filter.
